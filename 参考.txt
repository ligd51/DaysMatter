### 📦 开源项目（GitHub / 可自行部署或改造）

#### 1. Countdown Day（Obsidian 插件）—— 最贴合你需求的开源方案
这是目前功能匹配度最高的开源项目，作者明确支持阳历/农历（含闰月）、倒数与正数、多档提前提醒。

- **核心功能**：支持**阳历与农历（含闰月）**，农历日期自动换算为当年公历；每个事件可设置**倒数**（距目标日还有几天）或**纪念日/正数**（已过多久）；提醒支持**多选提前天数**（如提前 7 天、3 天、当天），触发 Obsidian 桌面系统通知；每年重复时可自动处理闰月、农历三十等边缘情况。
- **使用方式**：它是 Obsidian 笔记软件的插件，每个纪念日就是一个 Markdown 笔记，数据完全本地化，适合喜欢用笔记管理一切的人。
- **平台**：Windows / macOS / Linux（Obsidian 桌面端）。
- **GitHub**：`zenpuro/countdown-day`。

#### 2. Soul倒计时 —— 桌面端的高颜值选择
如果你想要一个常驻桌面的小工具，而不是笔记插件，Soul倒计时很合适。

- **核心功能**：同时管理多个倒计时/正计时事件；**农历日期支持**，内部自动转换为公历计算；提醒方式丰富，支持**托盘消息、本地音频、邮件**三种组合；界面支持毛玻璃、渐变背景、窗口透明度调节。
- **平台**：Windows / macOS / Linux（基于 PySide6 的桌面应用）。
- **开源状态**：作者已开源，可自行编译或查看源码。

#### 3. Countdown-App —— Android 端的轻量无广告选择
如果你主要在手机上使用，且希望完全本地、无广告，这个 Android 项目值得一看。

- **核心功能**：**阳历/农历日期**、普通倒数日、**每年重复纪念日**、事件置顶、自定义卡片背景、导出卡片图片。
- **特点**：作者因为“不想看广告”而自己写的，完全本地运行，轻量纯粹。
- **平台**：Android。
- **GitHub**：`LaoYinBai/Countdown-App`。

> 另外，`KangLin/LunarCalendar` 是一个用 Qt 写的**农历日历库**，本身不是完整的纪念日 App，但如果你打算自己开发，它提供了阳历/农历周年纪念日、节日、闰月等底层能力，可以作为开发基础。

### 🤖 Codex 提示词（如果你想自己做一个）

搜索结果显示，已经有不少人用 Codex / Cursor 做过类似的倒数日 App。如果你希望得到一个完全按自己想法来的工具，可以把下面这段提示词直接粘贴给 Codex（或 Claude、Cursor 等）：

> **提示词：**
> 请帮我开发一个跨平台的纪念日管理应用（或 Android/iOS 原生 App），应用名称暂定“记念”。
>
> **必须实现的核心功能：**
> 1. 日期记录：支持添加纪念日，字段包括标题、日期、备注、分类。
> 2. **阳历/农历双支持**：用户添加日期时可选择“阳历”或“农历”；如果选择农历，需支持闰月，并自动计算每年对应的公历日期用于展示和提醒。
> 3. **倒计时与正计时**：对未来的日期，显示“还有 X 天”；对过去的日期，显示“已经 X 天”。需要同时展示 **X 天**和 **X 年**（如“3 周年”、“第 1024 天”）。
> 4. **提醒**：支持设置提前 N 天提醒（可多选，例如提前 7 天、3 天、当天）；每年重复的纪念日，每年自动触发提醒。
> 5. 数据本地持久化，无需登录，不请求网络权限（除非用户主动启用同步）。
>
> **技术要求：**
> - 如果是移动端，优先 Android（Kotlin + Room）或 Flutter；
> - 如果是桌面端，优先 Python（PySide6）或 Electron；
> - 农历转换请使用成熟的开源农历库（如 `lunar-java`、`lunar-javascript` 或 Python 的 `lunardate`、`zhdate`），不要自己手写农历算法。
> - 界面保持简洁，核心列表页展示“标题 + 日期 + 农历标注 + 大数字天数”。
>
> 请先给出项目结构和技术选型，然后逐步实现核心数据模型和农历转换逻辑，最后完成 UI 和提醒功能。
