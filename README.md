# 记念 · Android 纪念日管理应用

「记念」是一款本地优先的 Android 纪念日应用。你可以记录生日、周年、节日、旅行或其他重要日子，支持阳历与农历、倒计时与正计时、年度提醒和主题切换。

应用不需要登录，不请求网络权限，数据保存在本机 Room 数据库中。

## 应用亮点

- Android 原生 Kotlin + Jetpack Compose。
- 本地保存，无账号，无联网。
- 阳历 / 农历双支持，支持农历闰月。
- 自动计算倒计时、正计时、第 X 天、N 周年。
- 年度事件自动计算下一周年。
- 多个提前提醒时间与自定义提醒偏移。
- 8 套主题，支持浅色 / 暗色 / 跟随系统。
- 长按卡片调整顺序。
- JSON 备份导入导出。

## 支持系统

- Android 8.0 及以上。
- 当前交付为 debug APK，版本 1.0.0。

## 功能说明

### 1. 纪念日管理

支持记录：

- 标题
- 分类
- 日期
- 日期类型：阳历 / 农历
- 农历闰月
- 备注
- 每年重复
- 提前提醒天数
- 提醒时间

支持操作：

- 新建
- 编辑
- 查看
- 删除
- 撤销删除
- 长按拖动排序

### 2. 阳历 / 农历

录入时可以选择：

- 阳历：使用系统 DatePicker。
- 农历：选择农历年、月、日，并可开启闰月。

规则：

- 农历年份范围：1901 至 2100。
- 闰月只在目标农历年存在时可用。
- 如果切换到没有对应闰月的年份，闰月会自动关闭。
- 农历三十不存在时自动回退到当月最后一天。
- 农历年度事件会按农历年计算下一周年。
- 阳历 2 月 29 日在平年自动回退到 2 月 28 日。

### 3. 天数与周年

首页和详情页会显示：

- 未来：还有 X 天
- 过去：已经 X 天
- 当天：就是今天
- 过去或当天：第 X 天
- 已满周年：N 周年
- 未满一年：未满 1 周年
- 年度事件：下个周年还有 Y 天

首页卡片同时显示公历和农历日期。

### 4. 提醒

支持提醒偏移：

- 提前 30 天
- 提前 7 天
- 提前 3 天
- 提前 1 天
- 当天
- 自定义提前天数

默认提醒时间：09:00。

提醒触发后：

- 如果是年度事件，会自动安排下一次提醒。
- 应用重启、系统时间变化、时区变化、应用更新后会重排提醒。

### 5. 排序

- 正常上下滑动浏览列表。
- 长按卡片后上下拖动可调整顺序。
- 顺序会保存到本机数据库。
- 新建事件会追加到当前列表末尾。

### 6. 主题

内置 8 套主题：

1. 蕉红
2. 暖阳橙
3. 矢车菊蓝
4. 翠微
5. 碧青
6. 柠檬黄
7. 梅洛粉
8. 皇家紫

外观模式：

- 跟随系统
- 浅色
- 暗色

### 7. 备份与恢复

应用使用系统文件选择器导入 / 导出 JSON，不需要存储权限。

导出内容：

- 全部纪念日
- 提醒规则
- 主题色
- 外观模式

导出文件名格式：

```text
记念-backup-YYYY-MM-DD.json
```

导入前会校验：

- JSON 格式
- 备份版本
- 必填字段
- 公历 / 农历日期一致性
- 提醒时间
- 提醒偏移
- 时间戳
- 排序值

导入需要二次确认，确认后会替换全部本地事件数据。

## 操作说明

### 首页

| 操作 | 效果 |
| --- | --- |
| 点击右上角齿轮 | 打开设置 |
| 点击右下角「+」 | 新建纪念日 |
| 点击卡片 | 进入详情页 |
| 长按卡片并上下拖动 | 调整顺序 |
| 左滑或右滑卡片 | 删除卡片 |
| 删除后点击「撤销」 | 恢复刚删除的事件 |

### 新建纪念日

1. 在首页点击右下角「+」。
2. 输入标题。
3. 选择「阳历」或「农历」。
4. 选择日期：
   - 阳历：直接选择日期。
   - 农历：选择农历年、月、日；如需要选择闰月，先打开闰月开关。
5. 选择或输入分类。
6. 按需填写备注。
7. 确认是否「每年重复」。
8. 选择提前提醒天数。
9. 点击提醒时间，设置提醒时刻。
10. 点击「保存」。

### 编辑纪念日

1. 在首页点击要修改的卡片。
2. 进入详情页后，点击右上角编辑图标。
3. 修改内容。
4. 点击「保存」。

### 删除纪念日

方式一：

1. 在首页左滑或右滑卡片。
2. 卡片删除后可在底部提示中点击「撤销」。

方式二：

1. 点击卡片进入详情页。
2. 点击「删除」。

### 查看详情

1. 在首页点击卡片。
2. 详情页可查看：
   - 标题
   - 分类
   - 倒计时 / 正计时
   - 周年信息
   - 公历日期
   - 农历日期
   - 提醒规则
   - 备注

### 复制日期信息

1. 进入某个纪念日的详情页。
2. 点击「复制日期」。
3. 系统会复制标题、公历日期和农历日期。
4. 界面显示「已复制」，2.5 秒后自动恢复。

### 调整顺序

1. 在首页长按卡片。
2. 感到轻微震动后上下拖动。
3. 卡片越过约一半高度时会自动交换位置。
4. 松手后顺序保存。

### 修改主题

1. 点击首页右上角齿轮。
2. 在「主题色」中选择 8 种颜色之一。
3. 在「外观」中选择跟随系统、浅色或暗色。

### 导出备份

1. 打开设置。
2. 进入「备份」。
3. 点击「导出备份」。
4. 选择保存位置和文件名。
5. 等待导出完成。

### 导入备份

1. 打开设置。
2. 进入「备份」。
3. 点击「导入备份」。
4. 选择此前导出的 JSON 文件。
5. 查看确认提示。
6. 点击「替换全部」。

注意：导入会替换当前全部纪念日数据，请先导出当前数据作为安全备份。

## 权限说明

### 通知权限

- Android 13 及以上需要授权。
- 未授权时提醒仍可能触发，但不会显示通知。

授权方式：

1. 打开设置。
2. 进入「权限」。
3. 点击通知权限右侧按钮。
4. 允许通知。

### 精准提醒权限

- Android 12 及以上建议开启。
- 未开启时仍可使用非精准提醒，但可能延迟几分钟。

授权方式：

1. 打开设置。
2. 进入「权限」。
3. 点击精准提醒右侧按钮。
4. 允许「闹钟和提醒」。

### 不需要的权限

应用不请求：

- 网络权限
- 存储权限
- 通讯录权限
- 定位权限

## 常见问题

### 为什么没有提醒？

请检查：

1. 是否已开启通知权限。
2. 是否已开启精准提醒权限。
3. 事件是否设置了提醒偏移。
4. 系统是否禁用了应用自启动。
5. 应用是否被强制停止。
6. 应用是否被电池优化限制。

### 为什么提醒可能延迟？

如果未开启精准提醒权限，系统会使用非精准闹钟，提醒可能延迟几分钟。部分国产 ROM 的电池策略也会延迟触发。

### 为什么农历日期看起来不是公历生日当天？

农历事件按农历规则换算公历日期。闰月和农历月长与公历不同，因此每年对应公历日期会变化。

### 为什么闰月开关不能打开？

只有当前选择的农历年确实存在该农历月的闰月时，闰月开关才会生效。

### 为什么导入备份会提示确认？

导入会替换当前全部事件数据。二次确认可以避免误操作覆盖现有数据。

### 更新安装会丢数据吗？

正常覆盖安装不会清空数据。请避免卸载后重装；卸载通常会删除应用私有数据。
